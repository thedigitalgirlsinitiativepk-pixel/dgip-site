Project requirements

What your capstone must include.

Tap a track to see its exact checklist. If your project ticks every box, it passes.

Build a working command-line program that solves a real problem, written the way a professional would write it.

Your project must

  • The program must run without errors from start to finish on a clean machine.
  • Use at least 4 functions, each with a single clear purpose and a docstring.
  • Handle bad input with try/except so the program never crashes on a typo.
  • Use lists or dictionaries to store and process data.
  • Write a README that explains what the program does, how to run it, and one example of its output.
  • Use clear variable names and comments where the logic is not obvious.

What to submit

A GitHub link (or a zip file) containing your .py file(s) and your README.

Build a multi-page, responsive website that you could show to a real client.

Your project must

  • Have at least 3 linked pages that share one consistent navigation and style.
  • Look right on both a phone and a desktop screen (flexbox, grid, or media queries).
  • Use semantic HTML such as header, main, section and footer.
  • Include at least one working JavaScript feature, such as a form check, menu or filter.
  • Be live online (GitHub Pages or similar) and have a README explaining the project.

What to submit

A GitHub link, your live link, and your README.

Build a single-page website from scratch, with no templates.

Your project must

  • Use a clean HTML structure with headings, paragraphs, lists and images with alt text.
  • Keep your styles in a separate .css file.
  • Use flexbox or grid for at least one section of the layout.
  • Use a consistent set of colours and fonts across the page.
  • Include a short README or comments explaining your choices.

What to submit

A GitHub link (or a zip file) containing your .html and .css files and your README.
