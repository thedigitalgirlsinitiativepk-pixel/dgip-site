Module 03 · Programming

Python Programming

A clean, readable language used everywhere from automation to data science to AI.

8–10 weeks · 5–7 hrs/week No experience needed 4 Learning Phases
Play learning game → All games

On This Page

The Roadmap Phase 01 — Python Fundamentals Phase 02 — Data Structures & Functions Phase 03 — OOP & File Handling Phase 04 — Applied Python Free Video Courses Download the E-Book

Python is often recommended as a first programming language because its syntax reads almost like English — and it's the same language powering data science, automation, and artificial intelligence at a professional level. This track takes you from your first print statement to building small real programs.

Beginner Friendly Foundation for Data Science Foundation for AI 4 Phases
Mentor TipPython's official style guide is called PEP 8 — skim it once early on so your code looks professional from the start.

The Roadmap

01

Python FundamentalsSyntax, variables, and control flow

Get comfortable with the building blocks every Python program shares, before moving on to anything more complex.

01
Set up PythonInstall Python and choose an editor — VS Code or a browser-based notebook both work.
02
Variables & data typesStrings, integers, floats, and booleans.
03
Input & outputprint() and input() — talking to the person running your program.
04
Conditionals & loopsif/elif/else, for loops, and while loops.
Practice ProjectBuild a simple calculator that takes two numbers and an operator from the user.
02

Data Structures & FunctionsOrganizing information and logic

This phase covers how Python stores collections of data, and how to package logic into reusable functions.

01
Lists & tuplesOrdered collections, indexing, and slicing.
02
Dictionaries & setsKey-value pairs and unique collections.
03
Writing functionsdef, parameters, return values, and default arguments.
04
ModulesImporting Python's built-in library instead of reinventing it.
Practice ProjectBuild a contact book stored as a list of dictionaries, with add / search / delete functions.
03

OOP & File HandlingStructuring bigger programs

Real programs are built from objects, and often need to read and write files — this phase introduces both.

01
Classes & objectsModeling real-world things as code — the basis of most large Python projects.
02
File input/outputReading from and writing to .txt and .csv files.
03
Error handlingtry / except so your program fails gracefully instead of crashing.
04
Using external librariesInstalling packages with pip and reading their documentation.
Practice ProjectBuild a personal expense tracker that saves entries to a file and calculates totals by category.
04

Applied PythonReal, useful mini-projects

This phase is about applying everything you've learned to programs that solve an actual problem.

01
Working with APIsRequesting live data from the internet using the requests library.
02
Simple automationWriting a script that automates a repetitive task — renaming files, for example.
03
Intro to data with PythonA first look at the pandas library for working with tabular data.
04
Code review habitsReading and cleaning up your own earlier code — an underrated skill.
Practice ProjectBuild a quiz app that pulls questions from a file or API, tracks score, and shows results at the end.
