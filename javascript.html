JavaScript Fundamentals

The language that makes websites interactive — from a button click to a full web app.

8–10 weeks · 5–7 hrs/week HTML & CSS basics recommended 4 Learning Phases
Play learning game → All games

On This Page

JavaScript is what turns a static page into an app — it's the language behind every dropdown menu, form validation, and live-updating feed you've ever used. This track takes you from your first variable to fetching real data from the internet and building an interactive project of your own.

Builds on HTML/CSS Project-Based Covers Async & APIs 4 Phases
Mentor TipBreak early and often — you'll learn more from figuring out why your code doesn't work than from code that works on the first try.

The Roadmap

01

Syntax & Core ConceptsHow JavaScript thinks

Every program is built from a small set of ideas repeated constantly: storing values, making decisions, and repeating actions.

01
Variables & data typeslet, const, strings, numbers, booleans — how JavaScript stores information.
02
Operators & expressionsArithmetic, comparison, and logical operators used to build any condition.
03
Conditionalsif / else / switch — how a program makes decisions.
04
Loopsfor, while, and for...of — how a program repeats work without repeating code.
Practice ProjectBuild a console-based number guessing game using conditionals and a loop.
02

Functions & the DOMReusable logic and a live page

Functions let you package logic once and reuse it anywhere. The DOM is how JavaScript reaches into HTML and changes it live, in the browser.

01
Functions & scopeDeclarations, parameters, return values, and arrow function syntax.
02
Selecting the DOMquerySelector and getElementById — grabbing the exact element you want.
03
Changing the DOMUpdating text, styles, and classes in response to code.
04
Event listenersResponding to clicks, input, and form submissions in real time.
Practice ProjectBuild a click counter and a simple light/dark mode toggle button.
03

Data Structures & LogicWorking with real, structured data

Almost every app deals with lists and structured records — this phase covers the tools built for exactly that.

01
Arrays & array methodsmap, filter, and reduce — the three methods used in nearly every JS codebase.
02
ObjectsKey-value data, nested objects, and accessing properties.
03
JSONThe universal format used to move data between a server and your app.
04
Debugging with the consoleconsole.log habits and reading browser error messages without panic.
Practice ProjectBuild a to-do list app: add, complete, and delete tasks, stored in an array and rendered to the DOM.
04

Async JavaScript & ProjectsTalking to the real internet

Real apps fetch live data from servers. This phase covers the async patterns needed to do that cleanly.

01
PromisesUnderstanding pending / resolved / rejected states.
02
async / awaitWriting asynchronous code that reads top-to-bottom, the modern standard.
03
The fetch APIRequesting real data from a public API.
04
Error handlingtry / catch so a failed request doesn't crash your whole app.
Practice ProjectBuild a weather-lookup or quote-generator app that fetches live data from a free public API.
